# drillcue

Drill digests and cue fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/drillcue/

## Install / run

```bash
git clone https://github.com/theworker02/drillcue.git
cd drillcue
node src/cli.js
node --test
```
